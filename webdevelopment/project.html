Projects & Experience

This portfolio highlights three key areas: Development & Design, System Administration & Self-Hosting, and Cloud Computing & Infrastructure. Each project shows my skills, challenges I faced, what I learned, and what I plan to improve.

Competency 1: Web Development & Design

MkDocs Portfolio Website

Description: I created a personal portfolio website using MkDocs to display my technical projects and skills. The website provides a well-organized space where I document my work and learning process. MkDocs makes it easy to write and update content using Markdown, and I added themes and plugins to make the site more visually appealing.

Technologies Used: Visual Studio Code, MkDocs, Python, GitHub Pages, Markdown, Material for MkDocs, CI/CD.

Reflection:

  • Strengths: Simple setup, easy navigation, automatic GitHub updates.
  • Weaknesses: Limited design options compared to traditional website builders.
  • Lessons Learned: I gained a better understanding of how version control keeps content organized and how static site generators work.
  • Future Improvements: I plan to test more MkDocs plugins and find ways to customize the design further.

Competency 2: System Administration & Self-Hosting

Home lab Setup and Self-Hosting

Description: I built and maintain a homelab environment where I explore open-source tools to manage and secure a personal network. This project helps me test new software, improve security, and host my own services instead of relying on third-party cloud providers.

Technologies Used: OPNsense, TrueNAS, Nginx Proxy Manager, Let's Encrypt, Docker, Proxmox.

Reflection:

  • Strengths: Hands-on experience managing servers, deeper understanding of networks and security.
  • Weaknesses: Requires regular maintenance, and some tools take time to learn.
  • Lessons Learned: Security is very important when self-hosting, and automation helps reduce manual work.
  • Future Improvements: I want to use more automation tools to make updates and security checks easier.

Competency 3: Cloud Computing & Infrastructure

AWS Cloud Practitioner Practice

Description: I studied AWS cloud computing by using a free AWS account to gain hands-on experience. I explored key AWS services like EC2, S3, IAM, and RDS, learning how cloud infrastructure works, how to keep systems secure, and how to manage costs.

Technologies Used: AWS (EC2, S3, IAM, RDS), AWS Console, CLI.

Reflection:

  • Strengths: Real-world cloud computing practice, better understanding of security and billing.
  • Weaknesses: Limited access to advanced AWS features without a paid account, figuring out cost optimization can be tricky.
  • Lessons Learned: Proper security settings for user roles are crucial, and managing cloud resources wisely helps avoid unnecessary costs.
  • Future Improvements: I plan to continue AWS and Azure certification training and explore more cloud automation tools.
